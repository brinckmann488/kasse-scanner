# Kasse-scanner (prototype)

Prototype af en scanner-app til opsamling af kirsebærkasser i marken.
Kører i browseren på en Android-telefon med en Bluetooth-stregkodescanner sat op som tastatur (ENTER efter hver kode).

- **Mark:** start tur, scan kasser (7-cifret kasse-ID, de to første cifre er plukkernummeret), fortryd, afslut tur.
- **Offline:** scanninger gemmes på telefonen og sendes, når der er net (i prototypen til en simuleret server på telefonen).
- **Pakkeri (demo):** simuleret vejning og afstemning pr. tur.

Ingen rigtige data sendes nogen steder hen. Alt ligger i browserens lager på enheden.
